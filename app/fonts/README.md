# Manrope

Unmodified variable font from the official Google Fonts distribution:
https://github.com/google/fonts/tree/main/ofl/manrope

Source file: `Manrope[wght].ttf` (weights 200–800), downloaded 2026-11-04.
Distributed under the included `Manrope-OFL.txt` (SIL Open Font License 1.1).

Loaded once through `next/font/local` in the root layout. The shared theme
references its CSS variable; no Google font request is required at build time
or in the browser. Emails use a separate plain font-family fallback stack.
